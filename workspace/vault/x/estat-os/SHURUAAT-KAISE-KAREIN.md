# Estat.OS — Aasan Guide

Ye file un logo ke liye hai jo technical nahi hain. Yahan koi mushkil shabd
nahi milega.

---

## Ye cheez hai kya?

Ye ek software hai jo aapki property office ka poora kaam ek jagah sambhalta hai.

Jaise ek register hota hai na office mein — usme property likhi jaati hai,
customer ka phone number likha jaata hai, kis agent ko kaam diya, kab site
visit hai. Bas wahi register, ab computer par.

Ye website banane ka software nahi hai. Ye **office chalane ka** software hai.

---

## Isme kya kya kar sakte hain?

| Aap kya karna chahte hain | Kahan jayenge |
|---|---|
| Aaj ka kaam dekhna | **Today** |
| Nayi property daalna | **Add a Home** |
| Saari property dekhna | **Listings** |
| Customer ki puchhtachh dekhna | **Enquiries** |
| Site visit ka time set karna | **Site Visits** |
| Society ya project add karna | **Societies & Projects** |
| Apne staff ki list | **Team** |
| Photo aur video | **Gallery & Media** |
| Website par form banana | **Forms** |
| Excel se data daalna ya nikalna | **Spreadsheet** |
| Mahine ka hisaab dekhna | **Reports** |
| Office ka naam, number badalna | **Office Settings** |

---

## Rozana ka kaam kaise chalega

1. Subah **Today** kholiye. Wahan dikh jayega — kitni nayi puchhtachh aayi,
   kisko aaj phone karna hai, aaj kitni site visit hai.
2. Nayi property aaye to **Add a Home** par jaakar bhar dijiye. Simple sawaal
   poochhe jayenge, bas.
3. Customer ka phone aaye to **Enquiries** mein uska naam add kar dijiye, aur
   kisi agent ko de dijiye.
4. Site visit fix ho to **Site Visits** mein date daal dijiye. Visit ke baad
   likh dijiye ki kya hua — aaya, nahi aaya, ya cancel.

Bas itna hi. Baaki system khud sambhal lega.

---

## Zaroori baat: aapka data surakshit hai

* Plugin band karenge to bhi **data delete nahi hoga**.
* Uninstall karenge to bhi **data delete nahi hoga** — jab tak aap khud
  settings mein jaakar "delete" na chunein.
* Kuch bhi permanently delete karne se pehle system aapse `DELETE` likhwayega,
  taaki galti se na ho jaye.
* Customer ke phone number aur email surakshit rakhe jaate hain.

## Install kaise karein

1. `estat-os-2.6.0.zip` file apne paas rakhein.
2. WordPress mein login karein.
3. Left side menu mein **Plugins → Add New → Upload Plugin** par click karein.
4. Wahi zip file chunein, phir **Install Now** dabayein.
5. Phir **Activate** dabayein.
6. Ho gaya. Left menu mein **Office** naam ka option aa jayega.

---

## Pehli baar kya karein

1. **Office Settings** kholiye. Apne office ka naam, phone, email, sheher
   bhar dijiye.
2. **Practice Mode** chalu kar dijiye. Isse kuch nakli property aa jayengi
   jinpar aap bina dar ke practice kar sakte hain.
3. Jab aa jaye samajh, to Practice Mode band karke nakli data hata dijiye.
4. Ab asli property daalna shuru karein.

## Language

Do bhasha hain — **English** aur **Hinglish** (Hindi, par English akshar mein).

Hinglish chunenge to "Add a Home" ki jagah likha aayega
**"Nayi Property Add Karein"**.

Badalne ke liye: **Office Settings → Language**.

Dhyaan rahe — sirf button aur menu ki bhasha badlegi. Aapki likhi hui property
ki detail waisi hi rahegi, wo nahi badlegi.

---

## Agar kuch gadbad lage

**Office Settings → Tools** mein kuch button hain:

* **Rebuild index** — agar search theek se kaam na kare.
* **Repair tables** — agar kuch data gayab lage.
* **Clear cache** — agar purani cheez dikhti rahe.

Ye sab surakshit hain. Inse aapka data nahi jayega.
