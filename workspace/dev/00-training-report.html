Maine open-source design + WordPress + real-estate plugin resources padhe. Ye raha saar — ek page mein.

1 Maine kya-kya consume kiya

WordPress rules

Official plugin guidelines

Admin page kaise bane, settings API, notice kab aur kaise dikhaye — WordPress apne rules hain. Inka palan = plugin store mein pass.

Design system

GitHub Primer, Material, Carbon, Fluent

Spacing, font size, colour, shadow — sabka fixed scale. "Anushasan" yahi se aata hai.

Component library

shadcn/ui + Radix

Aaj kal ke best button, table, form, dialog, tabs — copy-paste pattern. Free aur open source.

Accessibility

WCAG 2.2

Contrast, minimum button size, error message ka tareeka, keyboard se chalana. Sabke liye usable.

Property sites

WP-Property, WPL, Showcase IDX, SimplyRETS

Listing, search filter, map, agent — in plugins ne 10 saal mein kya seekha, wahi uthaya.

UX research

Search & empty-state studies

Filter chips, half-map view, "0 result" page, onboarding checklist — conversion kaise badhta hai.

4 Ab aapki baari — ye 5 cheezein bata dein

  • Kaun use karega? Sirf aap, ya agents bhi khud listing daalenge?
  • Listing data kahan se aayega? Haath se type, ya kisi software/Excel/API se?
  • Visitor ko site par kya chahiye? Property dhoondhna, ya aapko lead milna — main kaun?
  • Koi pasandi ke rang ya brand? Nahi hai to main 2 option bana dunga.
  • Hindi + English dono chahiye site par?

Aage ka plan: aap ye batao → main aapko 3 visual mockup dunga (rang + layout ke saath) → aap ek chuno → design system file lock.
