# Compatibility Model
Detector reports Mayfair Core, Mayfair Forms & Leads, ACF, Elementor/Pro, WooCommerce, WP/PHP versions, existing `property`, `project`, `insight`, `mpd_*`/`mayfair_*` taxonomies and Mayfair-like REST namespaces. It makes no writes. Existing entities cause Compatibility to be recommended. Standalone is recommended only when no signal exists. Migration is an explicit future administrator action. Phase 1 registers no CPT/taxonomy and therefore cannot collide. Detection is heuristic until a sanitized Mayfair inventory supplies exact plugin constants/slugs/namespaces.
